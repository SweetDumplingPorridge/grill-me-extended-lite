# 让其他用户与 agent 改造

GitHub 仓库用于初次安装、下载版本、阅读源代码与 fork；正常访谈不拉仓库、不运行服务、不需要部署。

改造当前访谈：读取用户实际目标、已确认决定和领域，用当前对话生成 JSON 批次。模板不决定问题。可以改变问题措辞、访谈顺序、领域成果章节，不能默认替用户选择、伪造验证或宣称永久保存。

改造插件本身：用户授权后 fork 仓库，更新 SKILL.md、参考和模板，修改插件 name/version，执行 GUI 回归与打包，再通过目标账号的 Plugin Creator 或可用插件安装途径创建/更新。在普通对话临时遵循仓库说明不等于安装。

保持边界：只把本轮问题与用户明确提交的答案放入 UI/消息，不上传全部对话。三份交付文档与插件配置分开；会话数据不提交到公开仓库。

原 MCP 版：https://github.com/SweetDumplingPorridge/grill-me-extended-cloud 。可部署、独立持久化、有原生 MCP Apps GUI；保留作为另一路线。Lite 不偷偷依赖它，也不删除它。
