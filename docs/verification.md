# 验证记录

本地 Windows：Python 离线 runner 12 项测试通过；Chrome 浏览器模拟宿主 5 项 GUI 测试通过，包括 320/390/1280 宽度、三种题型、无预选、空答验证、私有草稿、失败重试、桥缺失、导出未提交草稿和导入消息。

状态测试覆盖：旧批次拒收、幂等重试且不同答案不能共用 ID、暂停/恢复、全量历史导入、人工改题后签名更新、非法状态/草稿拒绝、轮次门槛、审核退回、取消后可导出、revision 冲突、原状态不覆盖、自动历史存档、状态面板渲染、Unicode 与脚本注入文案。

浏览器测试使用模拟 window.openai 和简化宿主 CSS，不等于真实 ChatGPT 平台验收。截图是模拟 UI，已检查手机宽度。ZIP 检查根布局、UTF-8、所有引用资源与完整性；插件 schema 另行校验。

真实账号尚未验证：一次创建安装、资源在新聊天可用、Chat 模式调用 Python runner、真实 Visualize 提交桥、手机调用和跨设备恢复。Firefox 自动化被浏览器 URL 策略支持限制停止；内置浏览器打开 ChatGPT 超时。没有绕过限制。

因此此版本以预览版发布。后续验收须在账号 Plugin Creator 创建后，使用新聊天完成 GUI→答案消息→runner 保存→导出→新聊天导入链路。任何一步缺失都不算用户目标完成。
