# 0.2.0 改造设计

用户提供完整 App Block 交接设计并授权更新。本次保留业务状态机与 JSON checkpoint，增加 App Block renderer（手动协议回传）、Markdown 正文覆盖层与独立格式修复命令。旧 Visualize 和原 MCP 仓库保留。

App Block 不执行 runner、不创建身份、不做自动回调。模型接收文本才执行权威命令。组件仅导出本轮草稿，完整历史由聊天导出。正文通过稳定隐藏定位标记映射机器字段，折叠完整记录确保无损与旧格式兼容。语义不明确时拒绝，agent 根据上下文优先修复并提供新副本，再校验导入；不猜测用户决策。

变更风险：真实宿主 App Block 发射协议属于客户端能力，HTML 片段本身不能保证可用；文件读档测试与客户端封装验收分开。安装升级仍由用户账号界面提供，发布包不会偷偷更新账号。
