# GUI Lite 设计（2026-10-07）

用户授权自己规划实现，新公开仓库与旧 MCP 仓库分开。目标：一次创建/安装，Chat 内随时调用，由当前对话生成领域相关问题，点选、补充、提交后继续，无需每次读取 GitHub 或部署服务。

选择技能加宿主交互可视化；文本版无法满足 GUI，远程 MCP 满足 GUI 但需要托管。Lite 使用宿主现有可视化，安装能力与 GUI 可用性要逐账号验证；不能承诺任意账号上传 ZIP 即可运行。

状态：宿主执行 Python 标准库离线 runner；state.json 为结构化状态权威；不启动 localhost MCP 或 HTTP 服务。每次修改检查 revision、原子写入并另存历史快照。明确提交走宿主消息桥，runner 检查 schema_id、submission_id、状态、题目与答案。GUI 可导出完整快照加未提交草稿，跨聊天导入新恢复分支；手动编辑后校验、重算批次签名。沙箱文件不视为永久存储，用户下载 JSON 存档。13 节计划、逐项自审与三份交接文档保留。

发行：Agent Plugins ZIP；单文件 Plugin Creator 安装套件；GitHub 源码与 fork 指南。优先账号私人创建，后续按需要公开目录发布；GitHub 不等于全账号插件目录。原 MCP 仓库保留部署包，不设置 GitHub archived 标志，不删除代码。

验收：无默认选择；三种题型；补充；空答校验；安全文案；320/390/1280 宽度；桥成功/失败/缺失；草稿恢复隔离；重试幂等 ID；实际宿主一次安装和新聊天调用尚须账号验证。

分享链接正文多种读取方式均未获取（只有标题可见）；以上以用户当前明确需求与官方文档为依据，不能宣称综合了未读正文。
